Política de privacidad

Fecha de entrada en vigor: agosto de 2026

Esta Política de privacidad describe cómo la aplicación “Keep in Sight” gestiona la información del usuario.

Recopilación y uso de información

La aplicación no recopila, almacena en servidores externos, vende ni comparte datos personales.

Las notas pueden incluir fotos, texto, etiquetas, fechas de vencimiento y ajustes de recordatorios. Esta información se almacena únicamente de forma local en el dispositivo del usuario y no es accesible para el desarrollador ni para terceros.

Fotos y cámara

El acceso a la cámara se utiliza únicamente cuando el usuario decide tomar una foto para una nota. El acceso a la fototeca se utiliza únicamente cuando el usuario decide añadir fotos existentes.

Las fotos añadidas a las notas y sus vistas previas se almacenan localmente y la aplicación no las sube a servidores externos.

Notificaciones

Si el usuario activa recordatorios, la aplicación utiliza notificaciones locales para avisar antes de la fecha de vencimiento de una nota. Los datos de los recordatorios se procesan localmente en el dispositivo.

Almacenamiento de datos

Las notas, fotos, vistas previas, etiquetas y ajustes se almacenan localmente en el dispositivo.

La aplicación no ofrece almacenamiento en la nube ni sincronización de las notas del usuario.

Servicios de terceros

La aplicación no utiliza servicios de analítica, redes publicitarias ni herramientas de seguimiento.

Seguridad

Los datos se almacenan localmente en el dispositivo. El usuario es responsable de mantener la seguridad de su dispositivo y de sus copias de seguridad.

Eliminación de datos

El usuario puede eliminar notas individuales y notas archivadas dentro de la aplicación. Al desinstalarla se eliminan sus datos locales, sujeto al funcionamiento del sistema operativo y a las copias de seguridad controladas por el usuario.

Privacidad de los menores

La aplicación no está dirigida específicamente a menores y no recopila deliberadamente información personal de menores.

Cambios en esta política

Esta Política de privacidad puede actualizarse periódicamente. Cualquier cambio se publicará en esta página.
